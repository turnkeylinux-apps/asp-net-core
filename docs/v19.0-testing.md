# ASP.NET Core v19 acceptance

## Dependency decision

The appliance uses Microsoft's Debian 13 repository for .NET 10 LTS, which is
supported on Debian 13 through November 2028. The build verifies Microsoft feed
key fingerprint `AA86F75E427A19DD33346403EE4D7792F748182B`. The example uses
EF Core 9.0.19 and stable Pomelo 9.0.0 with a retained NuGet lock file. Pomelo
is the provider that supports this appliance's MariaDB database. Debian
supplies Nginx and MariaDB.

## Deferred issues

- NuGet package upgrades remain supervised because provider and EF Core
  versions must stay compatible with the sample source.
- Pomelo has not released an EF Core 10 provider. Move both packages to the
  stable 10 line when it is available and passes MariaDB acceptance.
- The example demonstrates database reads and persistence. It is not an
  authentication or administration product.
- Docker acceptance does not repeat installer, kernel, or hardware checks.
- The Docker kernel rejects the appliance hostname firstboot call and the
  `systemd-sysctl` unit. These inherited container limitations do not affect
  the explicitly tested application services.
- Restarting ASP.NET can expose a brief proxy 502 while Kestrel starts. The
  supervised restart test retries through that bounded window and passed.
